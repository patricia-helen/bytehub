# ByteHUB

Sistema open source de gestão de liga acadêmica.

## Tecnologias

Java 21 · Spring Boot 4 · Spring Security · JWT · PostgreSQL · Docker · Swagger

## Status

🚧 Em desenvolvimento

## Sobre

Sistema desenvolvido com base em requisitos levantados junto à Liga Acadêmica ByteBuilders da UFVJM. Gerencia membros, grupos (guildas e projetos), encontros, presenças e histórico de gestões.
